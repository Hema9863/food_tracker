# My Food Tracker v9

Mobile-friendly South Indian food tracker with:
- Simple email-based profile selection — no password or signup
- Breakfast, Lunch, Dinner and Snacks
- Multiple foods per meal with automatic meal/day totals
- Date-wise history and CSV download
- Weight tracking and trend chart
- Large South Indian/Indian starter food list
- Custom foods

**Start here:** read `SETUP.md`.

If you already have v8 deployed, use `supabase_v9_migration.sql` and replace the app files; you do not need to create a new project.
